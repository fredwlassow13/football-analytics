# Bandeiras — Copa do Mundo 2022

32 bandeiras da coleção lipis/flag-icons, versão v7.3.2, formato 4:3.
SVGs originais em `svg/`; PNGs derivados de 320 × 240 em `png/`.
Licença MIT preservada em `LICENSE.txt`.

`catalogue.json` associa cada bandeira a `provider=statsbomb` e
`external_team_id`, conforme o arquivo de partidas da competição 43, temporada 106.
Os nomes em português são rótulos de apresentação; os nomes da fonte também são preservados.
Os caminhos das imagens são relativos a esta pasta.

O catálogo registra URLs de origem, versão, hashes SHA-256, tamanhos dos arquivos
e a ferramenta usada na conversão para PNG (resvg-py 0.5.0).
Inglaterra usa `gb-eng`; País de Gales usa `gb-wls`.

Este download não altera métricas, banco de dados ou renderizadores dos plots.
A integração das imagens ao renderer será uma alteração separada.
